## 0.1.0 — 2026-10-12

First public release.

- Bootstrap 5.3 theme in the Windows 3.1 style: buttons, forms, cards, tables, navbar, dropdowns, tabs, pills, breadcrumb, pagination, alerts, badges, progress, spinners, list groups, accordion, modals, offcanvas, toasts, tooltips, popovers.
- 12 colour schemes after the Control Panel palettes.
- Desktop with 8 one-bit 8×8 patterns and 3 wallpapers.
- Windows: sizing border with corner notches, title bar with control-menu box and min / max / restore buttons, inactive state, menu bar, MDI workspace, split pane, toolbar, status bar.
- Program icons, minimised icons, program-group glyph, file glyphs, directory tree, message-box symbols, Setup gauge, hourglass spinner, 3-D controls mode, scroll bars.
- Demo page (`site/index.html`) and a minimal starter template.
