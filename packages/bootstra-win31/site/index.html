Change the colour scheme and the desktop pattern in Control Panel. Click a window to activate it, minimise it to the desktop, or maximise it.

Links are green, like jumps in a Help file. Dotted ones open a popup.

Getting Started

The theme is one CSS file with no images, fonts or JavaScript. Load Bootstrap 5.3 first, then the theme:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstra-win31@0.1/dist/bootstra-win31.min.css">

Pick a colour scheme and a desktop on <html>, then write normal Bootstrap markup:

<html data-w31-scheme="default" class="w31-desktop w31-pattern-weave">

A window is three blocks inside .w31-window: a title bar, an optional menu bar, and a body or workspace.

<div class="w31-window">
  <div class="w31-titlebar">
    <button class="w31-sysmenu" aria-label="Control menu"></button>
    <span class="w31-title">Notepad</span>
    <button class="w31-ctl w31-ctl-min" aria-label="Minimize"></button>
    <button class="w31-ctl w31-ctl-max" aria-label="Maximize"></button>
  </div>
  <nav class="w31-menubar"><a href="#"><u>F</u>ile</a></nav>
  <div class="w31-window-body">…</div>
</div>

Theme classes

ClassWhat it is
.w31-desktop, .w31-pattern-*, .w31-wall-*Desktop colour with an 8×8 pattern or a wallpaper
.w31-window (.is-inactive, .w31-dialog, .w31-maximized)Window with sizing border and corner notches
.w31-titlebar, .w31-title, .w31-sysmenu, .w31-ctl-min/max/restoreTitle bar and its buttons
.w31-menubarMenu bar (links, dropdowns, or .navbar.w31-menubar)
.w31-window-body, .w31-workspace, .w31-splitWindow body, MDI workspace, two-pane split
.w31-toolbar, .w31-statusbar > .w31-statusTool bar and sunken status panes
.w31-icons > .w31-icon, .w31-desktop-icons, .w31-glyph-groupProgram icons, minimised icons, program-group glyph
.w31-file-*, .w31-files, .w31-treeFile glyphs, file list, directory tree
.w31-msgicon-*Information, question, warning and stop symbols
.w31-gaugeSetup gauge with colour-flipping percentage
.w31-groupbox, .w31-3d, .w31-btn-dialogGroup box, 3-D controls look, dialog-width button
.w31-raised, .w31-sunken, .w31-field, .w31-key, .w31-popup-linkBevel utilities, menu shortcut, popup link

Bootstrap components need no extra classes: buttons, forms, cards, tables, navbar, dropdowns, tabs, pills, breadcrumb, pagination, alerts, badges, progress, spinners, list groups, accordion, modals, offcanvas, toasts, tooltips and popovers are all restyled.
