bootstra-irix

Every component in the theme, each with a live example and the markup to copy. Load Bootstrap 5.3 first, then the theme. The JavaScript file is optional: without it, thumbwheels, clocks, view modes and window buttons are static.

Colour schemes

Put data-scheme on <html> for the whole page, or on any element to scope it. With no attribute the theme follows the system: IndigoMagic in light mode, Potrero in dark mode. Buttons with data-ix-scheme switch and remember the choice.

Tokens

All colours are custom properties, so swatches below change with the scheme. Define your own scheme by redefining them under [data-scheme="yours"].

Window

.ix-window is the bevelled frame. The title bar holds the window-menu button on the left and shade / maximize on the right; both work with the JS. Add data-ix-drag to drag by the title bar on wide screens, and .is-active for the highlighted title.

Menu bar & menus

Menu titles are italic bold with the mnemonic underlined (<u>). Use Bootstrap dropdowns inside; .ix-menu-help pushes Help to the right. Keyboard hints go in <kbd>. Open menus always float above other windows.

Toolchest

The cascading launcher from the top-left of the desktop. Each entry is a .dropend. If the Toolchest is not inside a window, put data-ix-layer on its container so open menus are raised above windows.

Desktop icons

Icons that sit directly on the desktop get a boxed label. Wrap them in .ix-desk-icons so clicks select one at a time.

Clock

An analog desk clock. The JS draws the face into any element with data-ix-clock and ticks every second.

Icon views

A view is a sunken area in one of four SGI colours: --teal for directories, --cadet for shelves, --catalog for the Icon Catalog and --navajo for search results. The tool strip on the left switches modes (data-ix-view="icons|list|compact"), opens a find bar (data-ix-find), and a thumbwheel resizes icons.

Icon set

Twelve original isometric icons, drawn as inline SVG. Put the class on an <i> inside .ix-icon, .ix-desk-icon or .ix-droppocket. Tint variants with a CSS filter.

<button class="ix-icon"><i class="ix-ico-folder"></i><span>Mail</span></button>
<button class="ix-icon"><i class="ix-ico-app" style="filter:hue-rotate(140deg)"></i><span>imgview</span></button>
Path bar & drop pocket

The directory-view header: a drop pocket that takes a dragged icon, the pink path field with depth ticks above it (set --ix-path-depth), and the rescan button.

Catalog tabs (Page 1 of 3)

Slanted tabs that hang under a view. They are ordinary Bootstrap tabs with .nav.ix-tabs. The active face takes the view colour: default catalog, or .ix-tabs--teal / .ix-tabs--navajo. Give tabs data-page and the window title a data-ix-page span to update “Page N”.

Applications: soundeditor, movieplayer, imgview.
Demos: buttonfly, ideas, insect.
DesktopTools: jot, xcalc, snapshot.
Thumbwheel

The ribbed wheel from SGI viewers. Drag it, roll the mouse wheel over it, or focus it and use the arrow keys, Home and End. It is a role="slider" and fires ix:change with detail.value.

zoom 50, rotate 0° 
wheel.addEventListener("ix:change", e => console.log(e.detail.value));
wheel.ixSet(75);   // set from code
Buttons

Raised Motif buttons that sink when pressed. The default (Enter) button, .btn-primary or .btn-default, gets the extra ring. Row them with .ix-btnrow to space them like an SGI dialog.

Text fields & option menus

Editable fields are SGI pink; read-only ones turn grey. .form-select becomes an option menu: a raised italic button with the dash indicator.

Saved with the host record.
Checks, radios, switches

Check boxes get the red tick. Radio buttons are Motif diamonds that fill yellow. Switches are a sliding block that turns green.

Range

A Motif scale with a bevelled thumb. Add .ix-vrange for the vertical faders of the Audio Panel.

Input groups & frames

Input-group labels are raised italic tabs. .ix-frame on a <fieldset> draws the etched Motif group box with its legend on the line.

Tables

Tables sit on navajo inside a sunken .ix-table-wrap, with raised italic headers. .num right-aligns numbers in the monospace face; .table-active marks the selected row.

Lists

A scrolling Motif list: .ix-list plus Bootstrap’s .list-group. Items with .list-group-item-action highlight on hover; .active is the selection.

Meters

Bootstrap progress bars become gr_osview meters on black. Stack them for CPU breakdowns. .ix-vu holds segmented level bars; set --level from 0 to 100.

Modals

Bootstrap modals become dialog windows with a title bar and an etched footer. Put a notifier inside for the IRIX confirm look.

Log Out
Log out of the desktop? Unsaved work in open applications will be lost.
Toasts & tooltips

Toasts are small windows. Tooltips are pale yellow help tags with a black outline; initialise them with Bootstrap’s Tooltip.

Desktop
Environment set up. Your desktop opens at next login.
