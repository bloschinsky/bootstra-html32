bootstra-irix

A Bootstrap 5 theme inspired by the Indigo Magic desktop of early-90s Silicon Graphics workstations. Bevelled frames, italic menus, thumbwheels, drop pockets, pink path fields and teal icon views — all as plain classes on top of Bootstrap.

Drag windows by their title bars, roll the thumbwheels, and switch schemes from the Schemes page or the Color Scheme Browser.
