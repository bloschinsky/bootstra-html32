# Changelog

Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versioning: [SemVer](https://semver.org/).

## [1.0.0] — 2026-10-17

### Added
- `bootstra-p31.css` theme for Bootstrap 5.3: `--p31-*` tokens mapped onto Bootstrap’s `--bs-*` variables.
- Three phosphor colours: green P31 (default), amber, cyan (`data-p31-phosphor`).
- Restyled components: buttons, forms, navigation, panels, accordion, tables, alerts, tags, progress, modals, toasts, tooltips, offcanvas.
- `p31-*` patterns: titlebox, memo, kv, steps, figure, log, stats, folders, keys, crt.
- Docs site in `docs/`, a starter template and the encyclopedia prototype in `examples/`.
- Build with `npm run build`, docs deployment to GitHub Pages.
