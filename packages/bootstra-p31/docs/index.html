bootstra-p31 for Bootstrap

This theme turns stock Bootstrap 5 components into the screen of an old research terminal. The grid, classes and JavaScript stay the same: you write ordinary Bootstrap markup and get a phosphor display.

Getting started START

Load the theme after Bootstrap and add the p31 class to the root element. data-bs-theme="dark" is needed so Bootstrap switches its built-in icons to their dark variants.

Root

html.p31 turns the theme on. Without it the page stays plain Bootstrap.

Phosphor

data-p31-phosphor="amber" or "cyan" on html recolours the whole screen.

CRT

body.p31-crt adds scanlines and a vignette on top of everything without catching clicks.

Colours TOKENS

The base palette lives in --p31-* variables. Bootstrap’s colours (primary, info, warning…) point at them, so changing the phosphor recolours everything at once.

Buttons .btn

Solid buttons are for the main action on a screen; outline buttons are for everything else. Labels are always uppercase and letter-spaced, like keys on a console.

Forms .form-*

Fields are “black glass” with a phosphor border. A focused field lights up in the secondary colour. The command line is an ordinary input-group.

Command>
Format: RES-, REC- or MAN- plus a number.
Chamber limit exceeded: 140 kPa.

Navigation .nav · .list-group

Sidebar folders are a list-group with the p31-folders modifier. The active item is inverted, and on desktop a connector runs from it to the content.

Document p31-titlebox · p31-memo · p31-steps

Custom classes for technical documents: a framed title, a memo header, numbered steps and a key/value list.

Figures p31-figure

Diagrams and charts are drawn in SVG with the classes p31-s (stroke), p31-f (fill), p31-t (text) and p31-gr (grid). The colour comes from the accent, so figures always match the screen.

System blocks p31-stats · p31-log · p31-keys

Stats, an event log and a key-hint bar: small details that make a page feel like a working screen.
